# Embedded System — เครื่องตัด/ป้อนวัสดุควบคุมด้วยรีโมต

โปรเจกต์ระบบฝังตัวบน ESP32 สำหรับกำหนดความยาวและจำนวนชิ้นงานผ่านแป้นกดหรือรีโมตไร้สาย โดยใช้ ESP-NOW สื่อสารระหว่างชุดควบคุมกับชุดเครื่องจักร ตัวรับอ่านเซนเซอร์ระดับท่อและควบคุมมอเตอร์สเต็ปเปอร์กับเซอร์โว

## ไฟล์ในโปรเจกต์

- `ตัวส่ง.txt` — โค้ดชุดรีโมต: อ่านแป้นกดและปุ่ม, ส่งคำสั่งผ่าน ESP-NOW และแสดงผลบน OLED
- `ตัวรับ.txt` — โค้ดชุดเครื่องจักร: รับคำสั่ง, แสดงหน้าจอ LCD, อ่านเซนเซอร์ IR และควบคุมมอเตอร์สเต็ปเปอร์/เซอร์โว

> ไฟล์โค้ดปัจจุบันเป็น `.txt` หากต้องการอัปโหลดด้วย Arduino IDE ให้คัดลอกแต่ละไฟล์ไปยังสเก็ตช์ Arduino แยกกัน แล้วบันทึกเป็น `ตัวส่ง.ino` และ `ตัวรับ.ino` ตามลำดับ

## อุปกรณ์และไลบรารี

อุปกรณ์ที่อ้างอิงจากโค้ด:

- บอร์ด ESP32 จำนวน 2 บอร์ด
- จอ OLED SSD1306 สำหรับชุดรีโมต และจอ LCD I2C 16×2 สำหรับชุดเครื่องจักร
- PCF8574 สำหรับแป้นกด และ PCF8574 สำหรับปุ่มชุดเครื่องจักร
- มอเตอร์สเต็ปเปอร์, เซอร์โว และเซนเซอร์ IR 3 ตัว
- แป้นกด 4×3 และปุ่มควบคุม

ไลบรารี Arduino ที่ใช้:

- `Adafruit GFX Library`
- `Adafruit SSD1306`
- `LiquidCrystal_I2C`
- `ESP32Servo`
- `Stepper`

`Wire`, `WiFi` และ `esp_now` เป็นไลบรารีที่มากับ Arduino core สำหรับ ESP32

## การเชื่อมต่อที่กำหนดในโค้ด

### ชุดรีโมต (`ตัวส่ง.txt`)

- I2C: SDA GPIO 21, SCL GPIO 22
- OLED: I2C address `0x3C`
- PCF8574 แป้นกด: address `0x20`
- ปุ่ม OK: GPIO 32; CANCEL: GPIO 33; BACK: GPIO 25; NEXT: GPIO 26

### ชุดเครื่องจักร (`ตัวรับ.txt`)

- I2C: SDA GPIO 21, SCL GPIO 22
- LCD 16×2: I2C address `0x27`
- PCF8574 แป้นกด: address `0x20`; PCF8574 ปุ่ม: address `0x38`
- Stepper: GPIO 19, 18, 5, 17
- Servo: GPIO 16
- เซนเซอร์ IR: GPIO 35, 32, 33

ตรวจสอบแรงดันไฟเลี้ยง, ขา SDA/SCL และผังขาจริงของโมดูลก่อนจ่ายไฟ เพราะการต่อวงจรอาจแตกต่างตามบอร์ดและอุปกรณ์ที่ใช้

## วิธีเริ่มต้น

1. ติดตั้ง Arduino IDE หรือ Arduino CLI พร้อม ESP32 Arduino core และไลบรารีที่ระบุไว้ข้างต้น
2. เปิดโค้ดแต่ละชุดในสเก็ตช์แยกกัน เลือกบอร์ด ESP32 ที่ถูกต้อง แล้วคอมไพล์และอัปโหลดไปยังบอร์ดที่เกี่ยวข้อง
3. ตรวจสอบ MAC address ของบอร์ด ESP32 ทั้งสองชุด และแก้ค่าในโค้ดให้ตรงกับอุปกรณ์ของคุณ:
   - ใน `ตัวส่ง.txt` ค่า `machineMAC` ใช้ส่งไปยังชุดเครื่องจักร
   - ใน `ตัวรับ.txt` ค่า `remoteMAC` ใช้ส่งหน้าจอกลับไปยังชุดรีโมต
4. เปิด Serial Monitor ที่ความเร็ว `115200` เพื่อตรวจสอบสถานะการเริ่มต้นและคำสั่งที่รับ/ส่ง
5. ทดสอบการทำงานของจอ, ปุ่ม, เซนเซอร์ และมอเตอร์ทีละส่วนก่อนใช้งานร่วมกัน

## การใช้งานคร่าว ๆ

1. ป้อนความยาว (มม.) ด้วยแป้นกด
2. กด NEXT เพื่อไปหน้าป้อนจำนวนชิ้น
3. ป้อนจำนวน แล้วกด OK เพื่อไปหน้าสรุป
4. ใช้ BACK เพื่อย้อนกลับ และ CANCEL เพื่อล้างข้อมูล

ปุ่มบนรีโมตถูกแมปเป็น `#` (OK), `D` (CANCEL), `*` (BACK) และ `C` (NEXT) ส่วนแป้นกดใช้ตัวเลข, `*` และ `#`

## หมายเหตุ

- โค้ดมีการกำหนด MAC address, ขา GPIO และ I2C address ไว้โดยตรง โปรดปรับให้ตรงกับการต่อวงจรจริง
- ค่า `STEPS_PER_MM` และความเร็วสเต็ปเปอร์ควรปรับเทียบกับกลไกจริงก่อนใช้งาน
- โปรเจกต์นี้เป็นโค้ดควบคุมต้นแบบ ควรทดสอบกลไกตัดและส่วนที่เคลื่อนที่โดยคำนึงถึงความปลอดภัย
